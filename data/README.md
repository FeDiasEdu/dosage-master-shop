# Dados do projeto

## `peptides.csv`
Base mestre de peptídeos e apresentações derivada de `base_peptideos.xlsx`.

Campos:
- `Codigo_Interno`
- `Pepítideo`
- `Dosagem`
- `Unidade`

Esta base é a fonte inicial para busca, filtros, catálogo e futura ligação com a camada científica.

## Fonte privada de fornecedores
A base `AURA_Final(1).xlsx` contém preços e fornecedores. Como o repositório é público, os dados comerciais reais não são versionados aqui. A aplicação deverá receber essa fonte por ambiente privado quando a funcionalidade de compras/custos for implementada.
